flight-agent · 机票自动比价
================================================

把左边的 flight-agent.app 拖到右边的「应用程序」文件夹即可完成安装。

※ 请务必先拖到「应用程序」再打开。直接在 DMG 里双击运行的话,macOS 会把应用
  放到一个临时只读位置运行(称为 App Translocation),容易出各种怪问题。


一、第一次打开(重要!)
------------------------------------------------
本应用没有购买 Apple 开发者签名,所以首次打开时 macOS 会提示
「Apple 无法验证…是否包含恶意软件」。这是未签名应用的正常提示,不是应用有问题。

请按下面**任一种**方式放行(只需做一次):

  方式 A(推荐,最简单)
    1. 在「应用程序」里找到 flight-agent,**右键点击图标 → 选「打开」**
    2. 弹窗里再点一次「打开」
    之后就可以正常双击使用了。

  方式 B(方式 A 无效时)
    1. 先双击一次,出现拦截提示后点「完成」/「取消」
    2. 打开「系统设置 → 隐私与安全性」
    3. 往下找到「已阻止使用 flight-agent」,点「仍要打开」
    4. 再双击一次,弹窗里点「打开」

  方式 C(命令行,适合熟悉终端的人)
    在「终端」里执行:
      xattr -dr com.apple.quarantine /Applications/flight-agent.app


二、需要什么
------------------------------------------------
* 一台 Apple Silicon 的 Mac(M1/M2/M3/M4)
* 已安装 **Google Chrome**(本应用复用你电脑上的 Chrome 抓取网页,不绑定、不上传任何数据)


三、怎么用
------------------------------------------------
1. 双击 flight-agent,会自动打开一个窗口(首次会自动启动一个专用的 Chrome);
2. 填出发城市、到达城市、日期,点「开始查询」;
3. 约 30~60 秒后按价格升序列出航班,并高亮最低价;
4. 想看多个网站的价格对比,勾选「全渠道比价」。


四、关于登录(想让「去哪儿」也出结果的话)
------------------------------------------------
* 携程:不登录也能查到航班,可以直接用。
* 去哪儿:**必须登录**,否则它只会返回「暂无符合条件的机票信息」。

本应用会用一个**独立的 Chrome 资料目录**(和你的日常 Chrome 完全隔离),
所以你只需要在它弹出来的那个 Chrome 里登录一次,以后就一直记着了。

温馨提示:登录后别把那个 Chrome 窗口完全退出,否则下次要重新登录。


五、数据与隐私
------------------------------------------------
* 所有查询都在你本机进行,结果存在
  ~/Library/Application Support/flight-agent/
* 不向任何服务器上传你的账号、Cookie 或查询记录;
* 本应用**只查询和比价,不会下单、不会支付** —— 买票请自己回到网站人工确认。


六、退出
------------------------------------------------
* 点界面右上角的「退出」按钮可停止本地服务;
* 抓取用的那个 Chrome 会保留(下次启动更快),想彻底关闭就手动关掉它;
* 如果想彻底清理,删除 ~/Library/Application Support/flight-agent/ 即可
  (注意:那里面也有你的登录态,删了要重新登录)。
